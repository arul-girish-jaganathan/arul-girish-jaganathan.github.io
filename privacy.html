Privacy Policy — Ruzoh Factory

Effective 24 October 2026

Ruzoh Factory ("the app") is the in-house publishing tool of Ruzoh Media. It is used only by the Ruzoh Media team, on Ruzoh Media's own Google Drive and YouTube accounts. It is not offered to the public, has no sign-up, and does not collect data about viewers or anyone else.

The app uses YouTube API Services. By using it you also agree to the YouTube Terms of Service, and Google's handling of data is covered by the Google Privacy Policy.

1. Google user data the app accesses

PermissionWhat the app does with it
YouTube — upload and manage videos
youtube.upload, youtube		Uploads Ruzoh's finished videos to Ruzoh's own channel, sets title, description, thumbnail, playlist, language versions, the time the video goes public and the "altered or synthetic content" label, and checks that the upload worked.
YouTube Analytics — read only
yt-analytics.readonly		Reads views and watch time of Ruzoh's own videos to write a short performance note.
Google Drive
drive		Reads finished videos, scripts and publishing details from Ruzoh's own Drive folders, and writes status and upload records back to those folders. It does not open other files.

2. How the data is used

Only to do the jobs listed above for Ruzoh Media's own channels. The app does not use Google user data for advertising, does not sell it, does not build profiles of people, and does not use it to train AI models.

3. Where the data is stored

  • Sign-in tokens: kept as encrypted secrets in Ruzoh Media's private GitHub repository and in a private folder on the team's own computer. Never in public files or shared folders.
  • Upload records (YouTube video ID, scheduled time, view counts): saved as small files in Ruzoh Media's own Google Drive.
  • The app has no other database and keeps no copy of Drive or YouTube data on any other server.

4. Sharing

Google user data is not shared with anyone, except the services that run the app's own steps for Ruzoh Media:

  • GitHub Actions (GitHub, Inc.) and Kaggle (Google): the computers that run the app's scripts. Files are processed there for the duration of a run.
  • xAI text-to-speech: receives only the text of Ruzoh's own scripts to create the voice-over.

Ruzoh Factory's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. Keeping and deleting data

Upload records stay in Ruzoh Media's Drive until the Ruzoh Media team deletes them. Access can be removed at any time at Google security settings → third-party access; the app then stops working until it is signed in again. To ask about or delete any data, email the contact below.

6. Cookies

This website uses no cookies and no tracking. Fonts load from Google Fonts.

7. Changes

If this policy changes, the new version is posted on this page with a new effective date.
