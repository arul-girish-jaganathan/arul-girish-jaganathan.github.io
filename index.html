Ruzoh Factory

Ruzoh Factory is Ruzoh Media's in-house publishing tool. It is used only by the Ruzoh Media team on Ruzoh's own Google and YouTube accounts. It is not offered to the public and has no sign-up.

What it does:

  • Reads finished videos and their titles, descriptions and thumbnails from Ruzoh's own Google Drive folders.
  • Uploads each video to Ruzoh's own YouTube channel and schedules the time it goes public, with the playlist, Tamil and Kannada titles and the "altered or synthetic content" label.
  • Reads basic numbers (views and watch time) for Ruzoh's own videos so the team can learn what works.
  • Writes a short status record back to the same Drive folders.

Ruzoh Factory uses YouTube API Services. Read how it handles data in the privacy policy.
